# Athena-Exporter

A Python exporter that queries AWS Cost and Usage Report (CUR) data through Amazon Athena and exposes cost metrics to Prometheus, enabling dashboards and reports that break down AWS spending by team and resource type.

I built this during my 2016–2019 tenure at a former employer as part of a cloud cost-reduction initiative I started. The initiative had two main components: tagging resources with their owning teams and making their costs visible. This exporter supplied the data needed to identify where spending was concentrated and prioritize cost-saving efforts.

The exporter was completed, deployed, and used internally. It was still in use when I last checked in 2024. This repository preserves the project as historical work; its current operational status is unknown.
